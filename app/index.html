Why no live AI extraction: turning free text into a recorded fact or a new hypothesis needs a real model call, which needs a server holding an API key. This is a static page with no server — and unlike the Google Maps key, an LLM key is a real secret that must never be embedded in client-side code anyone can view-source. SPEC.md §5 already names the real fix (a serverless function holding the key) for when this moves off local-only. Until then, notes saved here are exactly what you typed, nothing more — capture_feedback.py is still the real, reviewable path from a note to a recorded fact.
